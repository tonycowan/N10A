# Awill

Where there's a will there's a way. Awill is a private journal you share with people you have added. You add someone by photographing their code.

**[Download the latest release](https://github.com/tonycowan/Awill/releases/latest)**

Releases include macOS, Linux, Windows, and an Android app.

Unsigned packages are built on [tonycowan/Prns](https://github.com/tonycowan/Prns) by `awill-macos-package`, `awill-linux-package`, `awill-windows-package`, and `awill-android-package`. The release workflow here downloads one successful run of each, checks that they share one Prns commit, Developer ID-signs the macOS apps, and can publish a GitHub Release.
